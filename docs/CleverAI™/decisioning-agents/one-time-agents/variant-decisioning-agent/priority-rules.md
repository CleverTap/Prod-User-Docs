# Overview

Priority Rules let you define clear rules that control which campaigns reach a user first, based on a campaign's channel and label. Use Priority Rules when you need to guarantee a particular team or channel's campaigns always take precedence, independent of how a Decisioning Agent would rank them.

The _Priority Rules_ page lists every rule in your account, in priority order. Click **Change priority** to reorder the rules.

## Create a Priority Rule

To create a Priority Rule:

1. From the _CleverTap dashboard_, navigate to _Decisioning_ > _Priority Rules_ under _Setup_, and then click **Create Priority Rule**.


<Image src="https://files.readme.io/ea3512f940c2b82bacfa75b0942c2283abc4b10d8093bfce09533ba3764595ff-image.png" align="center" caption="Priority rules" border={true} />



<Image src="https://files.readme.io/033cc80f4afd699786faa7cd8b572b3b5d5dad514f8b90eae8451a568327d249-image.png" border={true} />


2. Enter a name in the _Rule name_ field.
3. Under _Define a rule_, set the conditions this rule applies to:
   a. For the first condition, set _Channel_ _is_ to the channel this rule applies to.
   b. Click **AND**, then set the second condition, _Label_ _is_, to the label this rule applies to.
4. Click **Create rule**.
