# Overview

The _Templates_ section helps you organize and standardize your messaging templates. You can save and reuse templates from the _Templates_ section to have consistent messaging.

<Callout icon="📘" theme="info">
  ### Custom Roles

  All users with custom roles have read access to Templates by default. However, the administrator must grant **write** access for any Template operations. For more information, refer to [Define Access for Custom Roles](doc:role-based-access-control#define-access-for-custom-roles).
</Callout>

# Supported Channels

The following channels are currently supported in the Templates section. We will soon start supporting more channels for template management in the Content Manager.

| Channel | Description                                                                                  | Documentation                                                                  |
| ------- | -------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------ |
| Email   | Design reusable email structures using drag-and-drop, pre-built layouts, or the HTML editor. | [Email Templates](https://staging.docs.user.clevertap.net/docs/email-template) |
| Push    | Create reusable push notification templates with rich media, carousels, timers, and more.    | [Push Templates](https://docs.clevertap.com/docs/push-templates)               |

# Template Operations

The _Templates Editor_ offers the following multiple options for both Push and Email templates:

- Grid / List View: Switch between <img src="https://files.readme.io/ac80074-list_view_icon.jpg" height="30px" width="30px" /> list and card <img src="https://files.readme.io/40d9260-tile_view_icon.jpg" height="30px" width="30px" /> view for templates.
- _Search Templates_: Search for a template by name using the search bar.
- _Sort Template_: Sort templates by Name, Created On, or Edited On in ascending or descending order.


<Image src="https://files.readme.io/c07ed7c40512bab8d5e497ca5816d7265b5c3dbef28643edf325e1e12d4ff250-2026-07-27_14-52-26.jpg" align="center" caption="Template Operations" border={true} />


### Individual Template Actions

Click the **⋮** (ellipsis) icon on any template card to access the following actions:

- Edit: Makes changes to the selected template.
- Clone: Creates a duplicate of the template that you can edit independently.
- Rename: Changes the display name of the template.
- Delete: Removes the template from the listing.
- Update Labels: Adds or updates labels on the template to help with organisation and filtering.


<Image src="https://files.readme.io/3a6898b-CMS_Templates_Options.jpg" alt="Template Options" align="center" caption="Template Options" border={true} />


### Bulk Templates Actions

Click **Selection Mode** in the toolbar to access bulk action for templates:

1. Select the templates you want to delete. Use **Select all** to select all templates on the page, or **Clear selection** to deselect.
2. Click the <img src="https://files.readme.io/70a339a-delete_all_icon.jpg" height="30px" width="30px" /> delete icon in the selection bar to delete all selected templates.


<Image src="https://files.readme.io/3f10d3bdcdbb441c85c7febc952732ac40778c570a56ebc94950df51503ec082-image.png" alt="Bulk Templates Actions" align="center" caption="Bulk Templates Deletion" border={true} />


<Callout icon="📘" theme="info">
  ### Template Deletion

  A template deleted from the template gallery does not affect the running campaign already using these templates.
</Callout>
