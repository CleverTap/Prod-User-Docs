# Overview

Journey goals determine when users exit a journey path and allow you to evaluate the effectiveness of your journey against a control group. Examples include increasing user registrations or boosting platform frequency.

Drag and drop a segment from the left navigation in the Define Goals step to configure a goal. A journey supports up to three goals. Users exit the journey as soon as they complete any one goal.


<Image src="https://files.readme.io/d824ddb-Define_a_Journey_Goal.gif" alt="1208" align="center" border={true} />


## Types of Goals

### **Action-based Goals**&#x20;

Users exit in real-time upon performing a specific action. For example, exit people as soon as they perform the _Charged_ event, where _item_ is _Red Nike Shoes_.


<Image src="https://files.readme.io/d361d8fe6b2b3e38876d229838be97ef47d482a595c8ede4bd10bfb6fe79ee38-Action-based_Goal.png" align="center" caption="Action-based Goal" border={true} />


### **Past Behavior Goals**

Evaluated once daily at midnight (12:00 AM). Users who meet the criteria are exited and will not continue in the journey. For example, exit people if they have spent at least $300 in the past week.


<Image src="https://files.readme.io/1d3f682195d2f0973a2c4720e342707f202560a9fef9ca8d694a1fb231abb0b9-Past_Behavior_Goal.png" align="center" caption="Past Behavior Goal" border={true} />


# Conversion Revenue Tracking

After configuring the goal criteria (the _Who_ section), you can optionally configure which event property represents monetary value for that goal. This enables CleverTap to attribute revenue to users who convert through the journey and surfaces those numbers in _Journey Stats_, _Node Stats_, and Journey Reports.

<Callout icon="📘" theme="info">
  #### Private Beta

  Conversion Revenue Tracking is currently released in Private Beta. If you want to enable this for your account, contact Customer Success Manager.
</Callout>

### Supported Goal Types

| Goal Type      | Revenue Tracking |
| -------------- | ---------------- |
| Action-Based   | Supported        |
| Inaction-Based | Supported        |

<Callout icon="📘" theme="info">
  #### Note

  Revenue tracking is also not available for goals based on Page Visit, Page Count, or Referrer entry criteria.
</Callout>

### Example: Single Event

You are building a cart-abandonment journey. Your goal is for users to complete a purchase, and you want to track the revenue those purchases generate.

| Goal Type    | Event   | Property |
| ------------ | ------- | -------- |
| Action-based | Charged | Amount   |


<Image src="https://files.readme.io/e0fd3ee576db555ddfa0525288bde1a26dcf700450772e7eb341dbfd62875b59-Single_Event_-_Revenue_Tracking.png" align="center" caption="Conversion Revenue Tracking: Single Event" border={true} />


<br />

With this configuration, whenever a user in the journey completes the goal by triggering the _Charged_ event, CleverTap reads the Amount property value and adds it to the journey's total revenue.

The Journey Stats page then shows:

- Target Group Revenue: Total `Amount` summed across all users who converted and were not in a control group
- Control Group Revenue: Total `Amount` from the control group users who also converted.
- Revenue Boost: The incremental revenue generated by the journey, calculated as the difference between Target Group Revenue and Control Group Revenue. This is then added to the journey's total revenue.&#x20;


<Image src="https://files.readme.io/b93ec3d369f384317b77308a5e1b81c63a2262eb1159e534dfaa26a275a98e82-Journey_Stats.png" align="center" caption="Journey Stats" border={true} />


<br />

### Example: Multiple Events

If your goal covers two separate conversion events, for instance, a user either completes a standard purchase (Charged) or upgrades their subscription (Plan Upgraded). You can map a revenue property for each:

| Goal Type    | Event         | Revenue    |
| ------------ | ------------- | ---------- |
| Action-based | Charged       | Amount     |
| Action-based | Plan Upgraded | Plan Value |


<Image src="https://files.readme.io/3c7d6421903f523d1cfa9d86f7d176c6ae45783e23691d1f8fcc1675727e3221-Multiple_Event_Revenue_Tracking.png" align="center" caption="Conversion Revenue Tracking: Multiple Events" />


CleverTap aggregates revenue across both events when calculating stats for that goal.&#x20;

If you modify the _Who_ criteria of the Goal and remove an event, the corresponding revenue row is automatically removed.


<Image src="https://files.readme.io/99b1fa3f8eca62bba47f0b3429609ac615394d19e86f4ca794e89292a4c96978-Modify_Who_Criteria.gif" align="center" caption="Modify Who Criteria of Goal Section" border={true} />


<Callout icon="📘" theme="info">
  #### Cloning Journey

  When you clone a journey across projects, the revenue configuration is copied. If the configured event does not exist in the destination project, the row is marked as invalid in the Goal section. You must remap it to a valid event before the journey can be published.
</Callout>
