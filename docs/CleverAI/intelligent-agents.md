# Overview

Intelligent Agents continuously evaluate and optimize performance at the impression level: the best time, channel, path, variant, product, and audience. This means every send reflects the latest signal instead of a decision made once and left alone.

IntelliTime and IntelliChannel decide when and where to reach each user. IntelliNode and IntelliAB continuously re-test Journey paths and campaign variants to keep the winning option in front of your audience. Recommendations and Predictions decide what to show each user and forecast what they are likely to do next. None of this requires you to manually set up or monitor an A/B test; the agent runs the evaluation in the background and adjusts as performance data comes in.
