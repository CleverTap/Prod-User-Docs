# Overview

CleverTap's File Based Import enables you to import large volumes of customer data from your cloud storage bucket directly into CleverTap. By uploading CSV files to a connected storage bucket, you can bring historical data, batch updates, and analytical outputs into CleverTap for segmentation, personalization, and campaign orchestration without requiring a live database connection.

# Import Data into CleverTap

File Based Import allows you to activate data stored in CSV files for customer engagement in CleverTap. Use this when you need to import historical records, perform bulk profile updates, or bring in data generated by external pipelines and batch processes.

## Key Benefits

The following are the key benefits of using File Based Import to bring data into CleverTap.

* **No Live Database Connection Required**<br />Import data directly from CSV files stored in your cloud storage bucket without setting up or maintaining a direct database connection. This makes File Based Import accessible to teams that do not have a data warehouse integration in place.
* **Works with Any Data Pipeline**<br />File Based Import is compatible with any workflow that can output a CSV file and deliver it to a cloud storage bucket. Whether your data comes from an ETL tool, a batch process, or a custom script, it can be imported into CleverTap.
* **Historical and Batch Data Ingestion**<br />Import historical records, perform one-time data migrations, or run periodic bulk updates to keep CleverTap user profiles and events in sync with your source systems.
* **Automated File Pickup**<br />Configure recurring import schedules to automatically detect and process new files from your storage bucket based on file name and timestamp patterns, without manual intervention.
* **Lightweight Integration**<br />No query writing or schema configuration is required. Define a file name pattern, map your CSV columns to CleverTap properties, and CleverTap handles the rest.
