# Overview

You can create, manage, and reuse email templates directly from the Content Manager. Email templates let you design and save reusable message structures, using drag-and-drop, pre-built layouts, or the HTML editor, that can be applied across campaigns for consistent branding.

To access Email Templates, go to _Content Manager_ > _Templates_ > _Email_.


<Image src="https://files.readme.io/1cf70b0105d31dd336bf2be0630bc94b56ad3427443a98026ac07c0af312b1d3-image.png" alt="Content Manager Templates Editor" align="center" caption="Email Templates" border={true} />


## Create Template

You can create a template that can be used across various campaigns. To create a template:

1. Go to _Content Manager_ > _Templates_ > Email.
2. Click **Create Template**.


<Image src="https://files.readme.io/fc68aa6-Create_Templates.jpg" alt="Create Templates" align="center" caption="Create Templates" border={true} />


3. After completing the steps to [create a template](https://docs.clevertap.com/docs/email-editor-templates#template-types), click **Save**. The _Save Template_ popup opens.


<Image src="https://files.readme.io/2da38d5136a7f4c8c13466c0d82395928892f0aaf59cef9b9e648493380a4f99-image.png" alt="save a template" align="center" width="40% " caption="Save a template" border={true} />


4. Enter a name and select a label for the template.

<Callout icon="📘" theme="info">
  ### Template names

  Template names can include letters, numbers (0-9), underscores (\_), periods (.), hyphens (-), and spaces. Names must begin with a letter. Additionally, the template name must be unique.
</Callout>

5. Click **Save** to save your template.

Add content to pre-built templates or customize and build your templates. To create a new template with drag-and-drop elements, refer to [drag and drop templates](doc:email-editor-templates#drag-and-drop-template).

You can also create a template from the HTML editor with a Rich Media template. For more information, refer to [Source HTML Editor](doc:email-editor-templates#using-source-mode).

You can also save the Email Template directly from engagements.

## Filter Templates

You can filter the templates to narrow down your search.

1. Navigate to _Content > Content Manager > Templates_.


<Image src="https://files.readme.io/c4e68db-Filter_Templates.jpg" alt="Filter Templates in Content Manager" align="center" caption="Filter Templates" border={true} />


2. Click _Filters_. You can filter templates based on the following criteria:

- _Time Period_: Filter and search by the template's creation period.
- _Editor Type_: Filter and search by the template type.
- _Amp Type_: Filter and search by AMP (Amp Accelerated Mobile Pages).
- _Labels_: Filter and search the template by the assigned label.
- _Created by_: Filter and search by the person who created the template.

3. Click **Clear Filters** to reset all applied filters.

## Use Email Templates in Campaigns

When creating an email campaign, you can select a saved CMS email template instead of building from scratch:

1. In the new email campaign, navigate to the _What_ section. Click **Go to Editor**.
2. Switch to the **Saved Templates** tab to view your saved email templates.
3. Search, filter, or browse to find the right template.
4. Select a template. The composer auto-populates with the saved content such as title, message body, media, deep links, and other fields.
5. Edit any fields as needed before sending or scheduling the campaign.

<Callout icon="📘" theme="info">
  ### Note

  Users with read-only access to Templates can view, preview, and apply email templates in campaigns, but cannot modify or save changes back to the Content Manager.
</Callout>
