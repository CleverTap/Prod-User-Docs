# Overview

Use IAM Role-based authentication to allow CleverTap to read from or write to your Amazon S3 bucket. CleverTap authenticates using its own AWS identity, and you grant that identity access to your bucket by applying a bucket policy generated by the CleverTap dashboard. No IAM user or access key is required, and no credentials are stored in CleverTap. This method works for both import and export connections.

The generated policy differs by connection type:

- **Import**: Grants CleverTap's IAM role `s3:GetObject` and `s3:ListBucket` on your bucket (read access).
- **Export**: Grants CleverTap's AWS account `s3:PutObject*` on your bucket path (write access).

<Callout icon="📘" theme="info">
  #### Note

  CleverTap's AWS account ID differs by CleverTap region. Always copy the policy from your own dashboard; do not reuse a policy from documentation, another project, or another region.
</Callout>

# Prerequisites

Ensure the following before proceeding further:

- An S3 bucket already created on AWS. For more information, refer to [Create S3 Bucket on AWS.](doc:amazon-s3#create-an-s3-bucket-on-aws)

- The bucket is added to the CleverTap dashboard with the correct _Folder_ value and _Configure with_ set to **IAM Role**. For more information, refer to [Add Bucket on CleverTap Dashboard](doc:amazon-s3#add-the-bucket-on-the-clevertap-dashboard). The _Folder_ value is inserted into the generated policy.

- AWS console access with permission to edit the bucket policy (`s3:PutBucketPolicy`) on the bucket.

# Configure with IAM Role

Setting up Amazon S3 for IAM Role authentication requires a bucket policy generated by the CleverTap dashboard and applied to your S3 bucket on AWS. No IAM user or access key is needed.

The setup involves the following three steps:

1. [Copy IAM Policy from CleverTap Dashboard](doc:authenticate-with-iam-role#copy-iam-policy-from-clevertap-dashboard)
2. [Apply IAM Policy to S3 Bucket on AWS](doc:authenticate-with-iam-role#apply-iam-policy-to-s3-bucket-on-aws)
3. [Configure Connection on CleverTap](doc:authenticate-with-iam-role#configure-connection)

If you already have a bucket policy on the bucket, add the CleverTap statements to it instead of replacing it. For more information, refer to [Apply Bucket Policy to Your S3 Bucket]().

## Copy IAM Policy from CleverTap

This section covers copying the IAM policy generated by the CleverTap dashboard. CleverTap pre-fills the policy with its AWS principal and the bucket name you entered under _Folder_.

To copy the policy, perform the following steps:

1. In the CleverTap dashboard, go to _Settings_ > _Partners_, and select the _Import center_ or _Export center_ tab.
2. Select **Amazon S3**, and then open your connection.
3. Click **Edit** to open the _Edit Amazon S3 Connection_ page.
4. Under _Configure with_, select _IAM Role_.
5. Copy the generated IAM policy using the copy icon.&#x20;

### Apply IAM Policy to S3 Bucket on AWS

Applying the policy to your bucket grants CleverTap access to it. The CleverTap dashboard labels the generated policy an IAM policy. On AWS, you apply it as the bucket policy of your S3 bucket (a resource-based policy), not as an IAM identity policy. For more information about AWS bucket policies, refer to [Adding a bucket policy using the Amazon S3 console](https://docs.aws.amazon.com/AmazonS3/latest/userguide/add-bucket-policy.html).

1. Log in to your AWS console and go to **S3**.

2. Select your bucket from the _Buckets_ page.


   <Image src="https://files.readme.io/1f50b88f2ed9f96ffbb29ba9cbb156ae35f9ab2a5dc7af1fa14e173b5add03a7-select_bucket.png" align="center" caption="Select Bucket - AWS S3" border={true} />


3. Go to the _Permissions_ tab and click **Edit** under _Bucket policy_.


   <Image src="https://files.readme.io/d91969dac48b7dcdb004da8885d9571f8177955d68b74f9f45b3773b2d8aac02-buket_policy.png" align="center" caption="Permissions and Bucket Policy - AWS S3" border={true} />


4. Add the policy:
   1. If the bucket has no existing policy, paste the policy you copied from CleverTap.
   2. If the bucket already has a policy, copy it to a safe place first. Then add only the objects inside the `Statement` array of the CleverTap policy to the existing `Statement` array. Do not paste the whole CleverTap policy, and do not replace the existing policy. Replacing it removes permissions that other systems depend on.

5. Click **Save changes**.


   <Image src="https://files.readme.io/a8e949397872f4f74e2ba4b814f110191d59518694b7e21bca84e9aee113f7ca-edit_bucket_policy.png" align="center" caption="Paste IAM Policy and Save Changes" border={true} />


## Configure Connection on CleverTap

Return to the CleverTap dashboard to complete the connection.

1. Confirm that you saved the bucket policy on AWS, and then return to the Amazon S3 connection page that you left open on the CleverTap dashboard.
2. Verify and save:
   - For **import**, click **Test Connection**. When the test succeeds, click **Save**.
   - For **export**, click **Save**. When you click **Save**, CleverTap uploads a test file to the specified bucket and region. The connection is saved only if the upload succeeds. Ensure the bucket policy was saved on AWS before clicking **Save**.

The Amazon S3 bucket is now configured on both the AWS console and the CleverTap dashboard.

# Troubleshooting

| Issue                                                                              | Cause                                                                                                                                      | Resolution                                                                                                                                |
| ---------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------- |
| AWS rejects the bucket policy with "Invalid principal"                             | The policy was copied from another source, or the principal account ID was edited.                                                         | Copy the policy again from your CleverTap dashboard without modification.                                                                 |
| AWS rejects the bucket policy with a resource error                                | The bucket name in the policy does not match the bucket you are editing.                                                                   | Fix _Folder_ on the CleverTap dashboard, copy the regenerated policy, and paste it again.                                                 |
| Existing integrations lose access after saving the policy                          | The existing bucket policy was replaced instead of extended.                                                                               | Restore the previous statements and add the CleverTap statements to the Statement array.                                                  |
| **Save** or **Test Connection** fails on CleverTap even though the policy is saved | _Block all public access_ is on and the policy includes a wildcard principal, or the region on CleverTap differs from the bucket's region. | The CleverTap policy uses a specific principal and is compatible with _Block all public access_. Confirm the _Region_ value on CleverTap. |

# Verification Checklist

Confirm the following before using the connection in production:

- Folder on the CleverTap dashboard matches the AWS bucket name exactly.
- The bucket policy on AWS contains the CleverTap statements and all pre-existing statements.
- The principal in the bucket policy matches the one shown on your CleverTap dashboard.
- **Test Connection** (import) or **Save** (export) succeeded on the CleverTap dashboard.
