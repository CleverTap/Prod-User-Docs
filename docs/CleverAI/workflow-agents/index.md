# Overview

Workflow Agents automate the core setup work behind Segments, Journeys, and Analytics, so you spend less time building and more time acting on what you build.

Segment Builder and Journey Builder turn a plain-language description into a working segment or journey, rather than a manual, rule-by-rule setup. Analytics Builder generates a report from a prompt. AI Schema and NPS Insights turn raw event and survey data into descriptions and insights without manual tagging or analysis. CleverTap MCP extends the same productivity gain outside the dashboard, bringing your CleverTap data into whichever AI assistant you already use.
