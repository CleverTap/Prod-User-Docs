# Overview

The flows tab within funnels visually displays the successive steps performed by the users for selected events.

<Image align="center" alt={1237} border={true} caption="View Flows" title="Click Flows Tab to View Flows" src="https://files.readme.io/6b5a6e4-Flows_tab.png" />

For example, if you create a funnel of _Added to cart_and _Charged_ events, the flows tab in _Funnels_ shows the number of times that the user performed _Added to cart_ and _Charged_ events based on the interaction depth selected.
