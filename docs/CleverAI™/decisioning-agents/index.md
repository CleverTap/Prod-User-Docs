# Overview

Decisioning Agents use reinforcement learning to continuously calibrate and adapt your engagement strategy at the individual user level. Instead of applying a single decision to an entire segment, each agent learns from user responses and adjusts its decisions for each user.

While Intelligent Agents optimize a specific decision, such as send time or channel, Decisioning Agents learn from outcomes across all of them. The Lifecycle Agent optimizes the content and sequence of messages toward a milestone, such as first purchase or KYC completion. The One-Time Agent optimizes a one-time campaign toward a conversion goal you define, within the channels and guardrails you set. Both agents operate within your frequency limits, holdout, and exploration settings.
