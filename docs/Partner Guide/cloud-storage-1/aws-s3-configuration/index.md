# Overview

CleverTap allows you to import and export user and event data to and from an Amazon S3 bucket. This document covers creating an S3 bucket on AWS, adding the bucket to the CleverTap dashboard, and selecting a configuration method. The method-specific steps are covered in separate documents.

With the Amazon S3 integration, you can:

- Import user profiles and events from files stored in your S3 bucket.
- Export profile and event data to your S3 bucket for analysis in BI tools or storage in a data warehouse.
- Encrypt exported data with your own AWS KMS key (SSE-KMS).

# Choose Configuration Method

CleverTap supports three methods to grant access to your S3 bucket. Select one before you begin.

| Method                                 | Import | Export | What you create on AWS                                                                                                    | Credentials stored in CleverTap     | Recommended for                                                  |
| -------------------------------------- | ------ | ------ | ------------------------------------------------------------------------------------------------------------------------- | ----------------------------------- | ---------------------------------------------------------------- |
| **IAM Role**                           | Yes    | Yes    | A bucket policy, generated by CleverTap, that grants CleverTap's AWS principal access to your bucket                      | None                                | Most customers. No long-term credentials to store or rotate.     |
| **Access Key**                         | Yes    | Yes    | An IAM policy, an IAM user, and an access key                                                                             | Access Key ID and Secret Access Key | Customers whose security policy requires a dedicated IAM user.   |
| **IAM Policy with SSE-KMS Encryption** | No     | Yes    | A customer-managed KMS key, a KMS key policy statement, an S3 bucket with SSE-KMS default encryption, and a bucket policy | KMS Key ARN                         | Customers who must encrypt exported data with their own KMS key. |

<Callout icon="📘" theme="info">
  #### Note

  - IAM Policy with **SSE-KMS** Encryption is available only for **export connections**. The import connection screen shows only Access Key and IAM Role.
  - IP whitelisting is **not supported** for S3 connections
</Callout>

# Prerequisites

Ensure the following before you begin:

- An active AWS account with permissions to create S3 buckets. Depending on your method, you also need permissions to create IAM policies and users (Access Key) or KMS keys (SSE-KMS).
- A CleverTap account with the Amazon S3 partner enabled.
- A globally unique bucket name. Refer to the bucket naming rules in [Create S3 Bucket on AWS](doc:aws-s3-configuration#create-s3-bucket-on-aws).

## Create S3 Bucket on AWS

This section covers how to create a general-purpose S3 bucket.&#x20;

If you are using IAM Policy with SSE-KMS Encryption, complete steps 1 to 8, create a KMS key as described in [IAM Policy with SSE-KMS Encryption](doc:doc:authenticate-with-iam-policy-using-sse-kms-encryption), and then complete steps 9 and 10.

To create an S3 bucket, perform the following steps:

1. Log in to the AWS console and search for _S3_ in the search bar.

2. Select **S3** from the search results.


   <Image src="https://files.readme.io/3cf847f09fe036c23254c9fbb05263e4bef75fe9b2213228231fb59a29103388-bucket_on_aws.png" align="center" caption="Create S3 Bucket" border={true} />


3. Click **Create bucket**.

4. Under _General configuration_, verify that the AWS Region matches the region you will select on the CleverTap dashboard. AWS pre-selects the region based on your current console region. If the regions do not match, the export connection cannot be saved.


   <Image src="https://files.readme.io/da8eaa27c10edb81c723875682279f624ce530e54b0f804cabcc0434b698f17f-region_s3.png" align="center" caption="Create Bucket and Select Region" border={true} />


5. Under Bucket name, enter a name for the bucket. You must enter the same name in the Folder field on the CleverTap dashboard.

   <Callout icon="📘" theme="info">
     #### Note

     Bucket names must be 3 to 63 characters, begin and end with a letter or number, and contain only lowercase letters, numbers, periods (.), and hyphens (-). Bucket names must be unique across all AWS accounts.
   </Callout>


   <Image src="https://files.readme.io/2d3c20f4a84d5e80927a9e2be9bf8106317576874d772af4c15fba4c2d604d92-Create_bucket.png" align="center" caption="General Configuration - AWS S3" border={true} />


6. Under _Object Ownership_, CleverTap recommends selecting _ACLs disabled_.


   <Image src="https://files.readme.io/dad91a1c1a1aea80237205a3c0c66dfcb041ba60f14860b5899b8bc9694ed52b-object_ownership_-_s3.png" align="center" caption="Object Ownership - AWS S3" border={true} />


7. Under _Block Public Access settings for this bucket_, select _Block all public access_.


   <Image src="https://files.readme.io/6a6247ce03f9731e2d39a306e415bbf30e0c04c7f43f0f1b499bf6d98cd84263-Block_public_access.png" align="center" caption="Block All Public Access - AWS S3" border={true} />


8. Under _Bucket Versioning_, select **Disable**.


   <Image src="https://files.readme.io/b28382cda36ab26b92c2b4e09fe1be0a4dc74cf7177703961562373506cd7aab-Bucket_versioning.png" align="center" caption="Bucket Versioning - AWS S3" border={true} />


9. Under _Default encryption_, select the encryption type that matches your configuration method:
   - [**Access Key**](doc:authenticate-with-access-key) or [**IAM Role**](doc:authenticate-with-iam-role): Keep the default selection of **Server-side encryption with Amazon S3 managed keys (SSE-S3)**.

   - **IAM Policy with SSE-KMS Encryption**: Select **Server-side encryption with AWS Key Management Service keys (SSE-KMS)** and paste the KMS key ARN that you copied in [Create KMS Key on AWS](doc:doc:authenticate-with-iam-policy-using-sse-kms-encryption#create-kms-key-on-aws) into the _AWS KMS key ARN_ field.
     <Callout icon="📘" theme="info">
       #### Note

       The integration works with the default settings. Check your organization's internal policies to determine whether any setting requires a change.
     </Callout>

10. Click **Create bucket**.

## Add Bucket on CleverTap Dashboard

This section covers how to enter the bucket details on the CleverTap dashboard. The details you enter here (in particular, Folder) are used to generate the policies for the IAM Role and SSE-KMS methods, so complete this section before the AWS policy steps.

To add the bucket, perform the following steps:

1. On the CleverTap dashboard, go to _Settings_ > _Partners_ and select **Amazon S3&#x20;**&#x6F;n the _Integrations tab_.


   <Image src="https://files.readme.io/b3f0ce305a6b5d740249c3d994f1d7f529c118e55c24171451edbe285df544c1-S3_Integration.png" align="center" caption="Select S3 Integration" border={true} />


2. Select the **connection type**:
   1. For **import**, select the _Import Connections_ tab.
   2. For **export**, select the _Export Connections_ tab.

3. Click **Add Amazon S3 Bucket**, then add the bucket details.


   <Image src="https://files.readme.io/f128dc0ca113133a6aa8cd9a0e606f17dcfaa4cca28272c4b549982c45efe285-Create_and_Add_Bucket_details.gif" align="center" caption="Add Amazon S3 Bucket" border={true} />


4. Under Configure with, select one of the following methods and refer to the corresponding document to complete the configuration:
   - [Access Key](doc:authenticate-with-access-key)
   - [IAM Role](doc:authenticate-with-iam-role)
   - [IAM Policy with SSE-KMS Encryption](doc:authenticate-with-iam-policy-using-sse-kms-encryption)

<Callout icon="📘" theme="info">
  #### Caution

  Do not click **Save** or **Test Connection** yet. Both actions contact your bucket and fail until the AWS-side permissions are in place. Keep this page open; you return to it at the end of the method-specific steps.

  Clicking Discard shows a Discard edits? confirmation and removes everything you entered.
</Callout>

## **Verify Connection**

After you complete the steps on AWS, return to the CleverTap dashboard.

- **Import**: Click **Test Connection**. CleverTap checks access by listing the bucket (and the subfolder, if specified) using the configured method. When the test succeeds, click **Save**.
- **Export**: Click **Save**. CleverTap uploads a test file to the bucket and region you specified. The connection is saved only if the upload succeeds.

If the test or save fails, refer to [Troubleshooting](doc:aws-s3-configuration#troubleshooting).

# Troubleshooting

| Issue                                                                               | Cause                                                                                                           | Resolution                                                                                                                                                                          |
| ----------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| AWS shows "**The specified bucket name is not available**" when creating the bucket | S3 bucket names are unique across all AWS accounts.                                                             | Choose another name; for example, append your company name or AWS account ID. Update **_the Folder_** on the CleverTap dashboard to the final name.                                 |
| Export **Save** fails; CleverTap cannot upload the test file                        | Bucket name or region on the CleverTap dashboard does not match AWS, or the AWS-side policy has not been saved. | Confirm _the Folder_ matches the bucket name exactly (case-sensitive), confirm _the region_, and confirm the bucket policy or IAM policy was saved on AWS before clicking **Save**. |
| Import **Test Connection** fails                                                    | The policy grants write but not read access, or the _Subfolder_ path does not exist.                            | Confirm the policy grants `s3:GetObject` and `s3:ListBucket`, and confirm the subfolder exists in the bucket.                                                                       |
| The generated policy contains a bucket name that is not yours                       | The _Folder_ field was empty or incorrect when the policy was generated.                                        | Correct the _Folder_ on the CleverTap dashboard; the policy regenerates. Copy the policy again.                                                                                     |
| Files cannot be decrypted after export                                              | SSE-KMS is enabled on the bucket, but your reader has no `kms:Decrypt` permission on the key.                   | Grant `kms:Decrypt` on the key to the IAM principal that reads the files. This is separate from CleverTap's access.                                                                 |

# FAQs

#### **What permission does CleverTap need?**

For import, CleverTap needs read access (`s3:GetObject`, `s3:ListBucket`) on the bucket. For export, CleverTap needs write access (`s3:PutObject`) on the bucket path. The _IAM Role_ and _SSE-KMS_ methods generate the exact policy for you.

#### **Can I use one connection for both import and export?**

No. Import and export connections are configured separately under _Import Connections_ and _Export Connections_. You can point both at the same bucket.

#### **Does the bucket have to be in the same region as my CleverTap account?**

No. Any AWS region works.
